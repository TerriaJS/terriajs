# Radius

Radius defines the overall shape language of the interface. It's a
system-level value rather than a per-component style: components use the
semantic radius tokens, so changing those makes the whole interface feel
sharper or softer without redesigning any component.

## Semantic radius

Use these on components. Fields have their own, so their shape can change
apart from the rest.
